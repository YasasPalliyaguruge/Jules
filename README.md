# Jules Wellness

![Jules wellness project cover](assets/recruiter/cover.png)

> **Current status:** Early Next.js interface prototype. The broader wellness journeys are not yet connected from the current application entry point.

Jules is an exploration of a future wellness interface built with Next.js, React, TypeScript, Tailwind CSS, and the App Router. The present root page is a minimal welcome screen, so this repository should not yet be presented as a complete wellness platform or clinical service.

## Run locally

```bash
npm ci
npm run dev
```

Open `http://localhost:3000` after the development server starts.

Before sharing a build, run the available project checks:

```bash
npm run lint
npm run build
```

## Planned direction

Potential journeys include mood tracking, therapist discovery, meditation, journaling, community resources, crisis-support information, and a personal dashboard. These are product directions rather than verified current features.

## Portfolio recommendation

Archive this repository until the main journeys are connected through working routes and navigation. Reintroduce it to the public portfolio only after the README, screenshots, and application behaviour match.

## Safety boundary

Any future mental-wellness functionality should clearly distinguish general wellbeing tools from medical or clinical care. Crisis resources must use verified local information and should not be presented as a substitute for emergency or professional support.
